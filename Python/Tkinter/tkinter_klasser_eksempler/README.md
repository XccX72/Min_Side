# Tkinter med klasser (OOP) – eksempler (IT2)

Disse eksemplene viser samme ideer som de grunnleggende filene, men organisert med klasser.
Målet er å lære en ryddig struktur som passer bedre til større apper (f.eks. pandas + tkinter).

## Hvordan kjøre
```bash
python 01_app_klasse.py
```

## Filoversikt
- `01_app_klasse.py` – minste mulige App-klasse (`tk.Tk`)
- `02_counter_app.py` – teller-app med metode-callbacks og instansvariabler
- `03_entry_label_app.py` – Entry + Label med oppdatering, alt i en klasse
- `04_frame_layout_app.py` – bruker `Frame`-klasser for struktur (enkel "view")
- `05_simple_mvc_app.py` – veldig enkel “MVC”: Model + View (App)

Tips: Start med 01 og jobb deg oppover.
